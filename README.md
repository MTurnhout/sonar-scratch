# sonar-scratch

A throwaway .NET solution with a few deliberate SonarQube issues: unused members and parameters, an empty statement, a
TODO, too many parameters, nested ifs, a hard-coded credential (a security hotspot) and suppressions of Sonar's rules by
`#pragma warning disable` and `[SuppressMessage]`. It exists to record SonarQube Cloud's answers for SharpEdit's
connected mode; nothing in it is real.
